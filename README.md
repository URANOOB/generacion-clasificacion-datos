# Generación y Clasificación de Datos

## Entrega 1 - Semana 3

Este proyecto fue desarrollado en **Java 8** usando **Eclipse**, y corresponde a la primera entrega del ejercicio de generación y clasificación de datos.

En esta etapa se implementó la clase **GenerateInfoFiles**, encargada de generar archivos planos pseudoaleatorios que serán usados posteriormente como entrada para el programa principal.

## Objetivo de esta entrega

Generar archivos de texto con información de:

- productos
- vendedores
- ventas realizadas por cada vendedor
